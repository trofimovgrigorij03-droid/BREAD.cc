HLEBUSHEK INJECTOR — один exe: сам ставит DLL в игру, в игре появляется меню с переключателями читов
Ничего искать и вводить вручную не нужно.

КАК ПОЛЬЗОВАТЬСЯ
  1. Собери проект (ниже) — получится ОДИН файл bin\Hlebushek_Injector.exe (DLL вшита внутрь).
  2. Запусти его (при ошибке доступа — от админа). Он найдёт Dizzy.exe или сам запустит игру из соседней папки,
     положит hlebushek_menu.dll в папку игры и загрузит её в процесс.
  3. В игре появится окно «ХЛЕБУШЕК Mod Menu». Нажимай переключатели — всё применяется сразу.
     Insert — показать/скрыть меню, F1 / F2 / F3 — быстрые переключатели (бессмертие / жизни / энергия).
  4. Убрать меню и DLL:  Hlebushek_Injector.exe --eject  (или «Выгрузить меню» в самом меню).
     При выгрузке оригинальный код игры восстанавливается.

ЧТО УМЕЕТ МЕНЮ
  Бессмертие          — враги и ловушки не наносят урон. Падение в воду/пропасть (урон 100) работает как в игре,
                        чтобы не застрять; хочешь иначе — скажи.
  Бесконечные жизни   — жизни не уменьшаются ниже 3.
  Вечная энергия      — энергия всегда 100.
  Множитель очков     — ×1 / ×2 / ×5 / ×10 на всё, что даёт очки.
  Быстрые действия    — полная энергия, жизни = 3, +1 000 / +10 000 очков.
  В шапке показываются текущие жизни, энергия и очки.

КАК ЭТО УСТРОЕНО (всё найдено разбором Dizzy.exe v0.5, ручной поиск не нужен)
  * В exe есть RTTI: найдены классы CActionEnergyUpdate / CActionAddLife / CActionAddScore и объект CGame.
  * CGame: +0x58 жизни (макс. 3), +0x5C энергия (0..100), +0x6C очки.
  * DLL ставит 3 хука: на метод отрисовки CGame (чтобы каждый кадр знать адрес объекта игры), на проверку урона
    и на начисление очков. Адреса считаются от базы образа, поэтому ASLR не мешает.
  * Перед установкой DLL проверяет версию exe (размер образа, время сборки) и байты в местах патчей. Если игра
    другой версии — меню покажет «Версия игры не поддерживается» и ничего не тронет.

СБОРКА (ТОЛЬКО 32-БИТ — Dizzy.exe 32-битный)
  Вариант 1, без установки компиляторов: залей папку в репозиторий GitHub → Actions → Run workflow →
            скачай артефакт Hlebushek_Injector.exe (.github/workflows/build.yml уже готов).
  Вариант 2, MinGW-w64: MSYS2 → консоль "MSYS2 MINGW32" → pacman -S mingw-w64-i686-gcc → build.bat.
  Вариант 3, Visual Studio: "x86 Native Tools Command Prompt for VS" → build.bat.

ЗАМЕЧАНИЯ
  * Только для одиночной игры и твоей собственной сборки.
  * Антивирус может ругаться на любой инжектор (LoadLibrary через CreateRemoteThread) — добавь файл в исключения.
  * Меню — отдельное окно поверх игры; в эксклюзивном полном экране может не показываться (в окне и F11 работает).
  * Код проверен на синтаксис и машинные байты хуков дизассемблированы, но запустить игру с DLL я не мог
    (в моей среде нет Windows). Если при первом запуске что-то не так — напиши, что именно, и я поправлю.
