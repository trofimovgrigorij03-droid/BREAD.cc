HLEBUSHEK INJECTOR v3 — один exe, который сам ставит DLL в игру; в игре красивое меню с переключателями
Ничего искать и вводить вручную не нужно: запустил, нажал на функцию — всё применилось.

КАК ПОЛЬЗОВАТЬСЯ
  1. Собери проект (ниже) — получится ОДИН файл bin\Hlebushek_Injector.exe (DLL вшита внутрь).
  2. Запусти его (при ошибке доступа — от админа). Он найдёт Dizzy.exe или сам запустит игру из соседней папки,
     положит hlebushek_menu.dll в папку игры и загрузит её в процесс.
  3. В игре появится меню «ХЛЕБУШЕК Mod Menu». Insert — показать/скрыть.
     F1 бессмертие | F2 жизни | F3 энергия | F4 все эффекты вкл/выкл | F5 сменить погоду
  4. Убрать меню и DLL:  Hlebushek_Injector.exe --eject  (или «Выгрузить меню» в меню). Код игры восстанавливается.
  Настройки меню и эффектов сохраняются в Hlebushek_menu.ini рядом с игрой.

ВКЛАДКИ МЕНЮ
  Игрок   — Бессмертие (урон -100 от воды/пропастей работает как в игре), бесконечные жизни, вечная энергия,
            множитель очков ×1/×2/×5/×10, быстрые действия (полная энергия, жизни = 3, +1 000 / +10 000 очков).
  Мир     — Скорость игры ×1.0…×4.0 и «Быстрый бег (Shift)» — пока зажат Shift, игра идёт быстрее.
            Погода: снег, дождь, гроза (с молниями), туман, светлячки, листопад; интенсивность и ветер.
  Эффекты — фильтры картинки (ночь, закат, сепия, ч/б, холод, ночное зрение, инверсия) с силой,
            ВХ / X-Ray (контуры объектов + подсветка тёмных мест), виньетка, сканлайны CRT.
  Герой   — «спинбот»: модель героя вращается (в любую сторону, скорость до 1080°/с), качается или зеркально
            «дёргается»; размер героя 50–120 %; радужный герой (цвет плавно меняется по кругу).
  Меню    — цвет акцента (7 цветов + радуга), тема (тёмная/светлая/AMOLED), прозрачность, размер, положение.

КАК РАБОТАЕТ МОДЕЛЬ ГЕРОЯ
  Игра держит спрайт-лист героя (Sprites/dizzy.tga: 44 кадра по 100x88, цвет-ключ в пикселе (0,0)) в памяти.
  DLL читает такой же файл с диска, находит копию листа в памяти игры (проверяет все форматы пикселей и порядок
  строк, сверяет 800 пикселей), запоминает оригинал и каждый тик записывает в лист кадры, повёрнутые/уменьшенные/
  перекрашенные. Игра сама рисует уже изменённого героя. При выключении или выгрузке оригинал возвращается.
  Файл Sprites\dizzy.tga должен лежать рядом с игрой (как и сама игра его использует).

КАК ЭТО РАБОТАЕТ (всё найдено разбором Dizzy.exe v0.5)
  * RTTI: классы CActionEnergyUpdate / CActionAddScore, объект CGame (+0x58 жизни, +0x5C энергия, +0x6C очки).
    Хуки на отрисовку CGame (адрес объекта каждый кадр), проверку урона и начисление очков.
  * Погода и эффекты рисуются прямо в кадр игры: подменяются SetDIBitsToDevice/StretchDIBits в таблице импорта
    (картинка копируется, обрабатывается и отдаётся игре; исходный буфер игры не портится).
  * Скорость: игра тикает мультимедийным таймером timeSetEvent(16 мс) с функцией 0x430420; DLL добавляет
    второй таймер на эту же функцию — тиков становится больше.
  * Перед установкой DLL проверяет версию exe и байты в местах патчей. Если игра другой версии — меню покажет
    «Версия игры не поддерживается» и ничего не тронет.

ОГРАНИЧЕНИЯ (честно)
  * Скорость ускоряет ВСЮ игру (героя, врагов, таймеры), а не только бег героя: отдельную скорость героя в коде
    найти не удалось. Замедление (<×1) не реализовано.
  * ВХ — это визуальный X-Ray по картинке (контуры + подсветка теней), а не чтение списка объектов:
    маркеры «предметов сквозь стены» потребуют отдельного разбора списка объектов игры.
  * Модель героя: если вкладка «Герой» пишет «текстура найдена», а на экране герой не меняется, значит игра
    рисует его не из этой копии листа — напиши, разберу дальше. Вращение уменьшает героя (до ~65 %), чтобы
    повёрнутый кадр не обрезался границей ячейки 100x88.
  * Меню — отдельное окно поверх игры; в эксклюзивном полном экране может не показываться (окно и F11 работают).

СБОРКА (ТОЛЬКО 32-БИТ — Dizzy.exe 32-битный)
  Вариант 1, без установки компиляторов: залей папку в репозиторий GitHub → Actions → Run workflow →
            скачай артефакт Hlebushek_Injector.exe (.github/workflows/build.yml уже готов).
  Вариант 2, MinGW-w64: MSYS2 → консоль "MSYS2 MINGW32" → pacman -S mingw-w64-i686-gcc → build.bat.
  Вариант 3, Visual Studio: "x86 Native Tools Command Prompt for VS" → build.bat.

ЗАМЕЧАНИЯ
  * Только для одиночной игры и твоей собственной сборки.
  * Антивирус может ругаться на любой инжектор (LoadLibrary через CreateRemoteThread) — добавь файл в исключения.
  * Код проверен на синтаксис; эффекты прогнаны под AddressSanitizer на кадрах разных размеров; машинные байты
    хуков дизассемблированы. Запустить игру с DLL я не мог (в моей среде нет Windows) — если что-то не так,
    напиши, что именно.
